# 研究清单（Research Checklists）

> 每个员工、每个行业类型都有必选/可选模块。未识别行业使用 universal + general 兜底，不会没有清单。

## macro

### 必选模块

| ID | 模块 | 作用 |
|---|---|---|
| growth | 增长 | GDP/工业/消费/投资/出口的方向与结构 |
| inflation | 通胀 | CPI/PPI/核心通胀与上下游价格传导 |
| liquidity_credit | 流动性与信用 | 利率、社融、M1/M2、信用利差 |
| fiscal_debt | 财政与地方债务 | 预算、土地出让、专项债、化债、付息压力 |
| external_fx | 外部与汇率 | 进出口、国际收支、汇率、资本流动 |
| policy | 政策 | 货币/财政/产业政策方向与掣肘，区分文件与预期 |
| demand_decomposition | 需求拆解 | C/I/G/X-M 谁拉动谁拖累 |
| market_validation | 市场验证 | 利率、信用、汇率、波动率是否验证判断 |
| scenarios_risks | 情景与风险 | 可证伪情景、最大触发器、传导链 |
| data_quality | 数据与口径 | 来源、时间窗、修订、缺口 |
