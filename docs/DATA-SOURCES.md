# 缺数据怎么取（DATA-SOURCES）

报告里每条「待证据补充」的结论，对应 need 的取数指引都在这里，也同步在面板里：**左栏「待你确认」→ 每条 need 下的「缺什么 · 怎么取？」按钮**（由 `config/data-sources.json` 驱动）。

拿到数据后：面板中栏「＋ 上传资料」传进 `vault/uploads/`（CSV/Excel/PDF 均自动转文本），我会登记为证据、重跑受影响员工并重编报告。

## 1. 锗价序列（N10/N11）

- **去哪取**：SMM 上海有色网 <https://www.smm.cn/>（小金属 → 锗：锗锭 99.99% / 二氧化锗，历史价格可导出）；亚洲金属网 <https://www.asianmetal.cn/>；免费替代：生意社 <https://www.100ppi.com/> 搜「锗锭」、长江有色 <https://www.ccmn.cn/> 小金属报价。
- **怎么取**：会员后台 → 选择品种 → 时间范围 2020-01 至今 → 导出 CSV；免费站按日/周复制表格。
- **格式**：`date,product,price_cny_per_kg,source,url`
- **费用**：SMM/亚洲金属多为付费会员；生意社/长江有色免费。
- **替代**：海关总署「8110/2825」项下锗相关产品月度出口均价；USGS Mineral Commodity Summaries 年度均价。

## 2. 锗矿储量/品位/权益资源量（N12）

- **去哪取**：巨潮资讯网 <https://www.cninfo.com.cn/> 搜 `002428` → 2025 年年度报告全文 →「资源储量」/「矿业权」章节；公司官网投资者关系；省市生态环境厅环评公示（储量核实报告）。
- **格式**：Excel：矿山/权益比例/保有储量(吨)/品位/可采年限/公告链接。
- **替代**：USGS 中国锗储量估计、自然资源部《中国矿产资源报告》。

## 3. 锗供需、库存、出口管制/收储原文（N17）

- **供需/库存/开工率**：安泰科 <https://www.antaike.com.cn/>、SMM 小金属月报、百川盈孚、中国有色金属工业协会。
- **政策原文**：商务部「出口管制信息平台」<https://exportcontrol.mofcom.gov.cn/> 搜「锗」；海关总署公告；收储看发改委/工信部/国家粮食和物资储备局公告。
- **格式**：公告 PDF/链接 + Excel（全球/中国产量、库存、开工率）。

## 4. 磷化铟合同/许可/良率（N13）

- **去哪取**：巨潮公告搜「日常经营重大合同」「投资者关系活动记录表」；深交所互动易 <https://irm.cninfo.com.cn/> 搜 002428；调研纪要（Choice/Wind 付费）。
- **格式**：Excel：对手方(可脱敏)/数量/单价区间/交付期/许可状态/来源。
- **替代**：公司投关电话/邮件问询（联系方式见年报）。

## 5. 锗终端需求分项（N18）

- **光伏装机**：国家能源局 <https://www.nea.gov.cn/> 月度/年度装机统计；CPIA 中国光伏行业协会年度报告。
- **低轨卫星**：中国航天科技集团发射公报、SIA 年度报告、公开发射统计。
- **AI capex**：微软/谷歌/亚马逊/Meta 财报与电话会；TrendForce/IDC 摘要。
- **军工红外**：全军武器装备采购信息网 + 上市公司公告。
- **格式**：CSV：年份/指标/数值/单位/来源链接。

## 6. 宏观验证（N15）：信用利差 / DR007 / 2Y 国债

- 中国货币网 <https://www.chinamoney.com.cn/> → SHIBOR（免费 connector 已接）；中债收益率曲线 <https://yield.chinabond.com.cn/> → 国债/中短期票据（AAA/AA），信用利差 = 同期限票据 − 国债。
- **DR007 注意**：中国货币网 `FrrHis` 提供的是 FR007/FDR007 **回购定盘利率**，不是 DR007 加权平均，不能替代；当前无稳定免费接口。可上传 CSV，或配置可选 Tushare（`repo_daily` DR007.IB，需积分）。
- **格式**：CSV：`date,series,value,unit,source`。

## 7. 产业链/光模块第三方来源（N19）

- Yole Group <https://www.yolegroup.com/>、LightCounting、Omdia、TrendForce、中国电子材料行业协会 <https://www.cemia.org.cn/>；券商产业链深度（慧博投研/发现报告）。
- **格式**：PDF/链接（含光模块结构与 InP 衬底用量）。
- **替代**：光模块厂商（中际旭创/新易盛）投资者交流、招股书行业章节。

## 8. 财报附注/股东结构（审计项）

- 巨潮下载 2026 年三季报/2025 年报 PDF → 搜「短期借款」「一年内到期」「应收账款账龄」「前五名客户」「利息费用」「前十名股东」。面板上传 PDF 会自动转文本。
- **格式**：PDF 或 Excel 摘录（科目/金额/同比/页码）。

## 9. WACC 参数（ERP / 债务成本 / 税率）

- ERP：Damodaran 国别风险溢价 <https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/ctryprem.html>；Rf：中债 10Y；债务成本：年报财务费用附注（利息支出/平均有息负债）；税率：年报「税项」章节。
- **格式**：说明 + 来源链接/页码。
