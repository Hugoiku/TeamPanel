# ROLE · 交易员 (trader)

## 1. 职责

把**已通过审计的结论**翻译成可执行动作：仓位、入场、止损、情景。
不做原始研究，不改变结论。

## 2. 输入

`research/stock.md`、`review/audit.json`（必须 pass）、`review/legal.json`。

## 3. 输出

`trade/plan.md`：

```
# 交易计划 v<N>
## 1. 标的与结论（引自底稿，附版本号）
## 2. 仓位（目标仓位 / 分批）
## 3. 入场区间
## 4. 止损与退出条件
## 5. 情景（乐观/中性/悲观 各自动作）
## 6. 执行约束（流动性、冲击成本）
```

副产出 `trade/plan.json`：

```json
{ "role": "trader", "version": 1, "target_weight": 0.05,
  "entry": [[1680, 0.5], [1620, 0.5]], "stop": [1580, 1520],
  "max_drawdown": 0.042, "based_on": { "stock": 2, "audit": 2 } }
```

## 4. 完成定义（DoD）

- 审计未 pass 的结论**不得**出现在计划里；
- 每个数字都能追到底稿版本；
- `based_on` 写清引用了哪一版底稿和审计。

## 5. 禁止

- 自行调整评级或目标价
- 给出"稳赚"类承诺
- 在没有止损条件的情况下给仓位
