# industry-method · 行业研究的分析框架

## 0. 先定目的（决定框架侧重）

- 二级市场（券商）：判断行业投资价值 → 落到「哪些公司值得投」，财报分析占比高；
- 一级市场（战投/VC）：产业链布局、收购竞品、细分赛道；初创期公司财报参考价值低，更看份额与估值逻辑；
- 咨询：行业规律/风险/机会/趋势，常配高管访谈。

## 1. 宏观分析（PEST，不必拘泥）

- 经济：GDP/CPI/进出口、货币与财政政策、经济体制与产业结构；
- 政治：体制、政局稳定性、投资/环保/进出口/行业专项政策；
- 文化：人口（总量/年龄/性别/教育/分布）、社会流动性（阶级/贫富差距）、消费心理（生活方式/传统/价值观）；
- 科技：专利数量与质量、相关产业技术。
注意：宏观多为**混合因子、间接影响**；跨国研究要把中外因素都纳入；要同时看存量与趋势（增量），不能只做静态分析。

## 2. 产业分析（六件事）

1. **市场规模与增速**：产业规模 = 现有市场规模 × 增速；核心指标 = 市场规模 + CAGR；「宽度」= 容量，「长度」= 增长（联动成熟度曲线）；
2. **生命周期**：导入 / 成长 / 成熟 / 衰退；不同阶段看经营风险、财务风险、产品差异、单位利润、产品特征；
3. **产业链**：上游供应商、下游购买者、潜在进入者、现有竞争者；供应商议价（市占率/转换成本/战略）、购买者议价（价格敏感度/相对议价能力）、进入障碍（结构性/行为性）、替代品威胁（同质化/生产率）；
4. **驱动因素与壁垒**：要素驱动（高级/初级生产要素）+ 相关支持性产业（上下游聚集）；壁垒 = 政策限制（许可/配额/进出口）+ 市场壁垒（规模效应/品牌技术）；集中度看 CR5，垄断度高可能超额利润，但需求差异会削弱垄断（餐饮 vs 手机）；
5. **供求分析**：供给看产能（产能利用率、库存周期、产品寿命、订单周期）；需求看整体购买力（人均可支配收入、贫富差距）+ 细分需求 + 替代品；
6. **产业结构**：产品结构（初级/中间/最终；劳动/资金/技术密集）+ 市场结构（完全竞争/垄断竞争/寡头/完全垄断）。

## 3. 公司与竞争者

- 战略：企业能力与资源（研发/生产/营销/组织/财务；有形+无形）、价值链（基础设施+基本活动）、商业模式（物流/信息流/资金流）、产品组合（品类长度与深度、波士顿矩阵）、财务指标（毛利率/现金流/ROE）；外部分析（机会威胁）+ 内部分析（优劣势）= SWOT；
- 战略选择：总体（发展/稳定/收缩；一体化/密集型/多元化）、职能（营销/生产研发/运营/人力/采购）、国际化（国际化/多国本土化/全球/跨国）；
- 竞争者：优势如何放大、劣势如何缩小；从产品/技术壁垒/渠道/用户增量存量/财务/组织/核心管理层比较；战略选择 = 蓝海 / 中小企业 / 基本竞争（成本领先/差异化/集中化）。

## 4. 消费者（6W6O）

基本属性（年龄/收入/性别/教育/地域）；购买动机与行为：What(产品)、Why(目的)、Who(购买者/决策者)、How(购买方式)、When(时机)、Where(场合)。

## 写好行业底稿的自检

1. 目的是二级/一级/咨询？框架侧重是否匹配？
2. 规模与 CAGR 有没有数、来源能否回溯 `[S#]`？
3. 生命周期阶段有没有判断依据？
4. 产业链议价/壁垒/集中度是否覆盖？
5. 供求两侧是否都写了，替代品是否提？
6. 公司/竞争者/消费者分析是否落到具体玩家与行为？
7. 没有数据的部分是否标「待补」并说明缺什么？
