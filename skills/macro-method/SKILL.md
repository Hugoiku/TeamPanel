# macro-method · 宏观经济研究框架与方法论

## 何时用

写宏观底稿、判断拐点、或给「对风险资产的含义」之前，按本清单逐项过一遍；缺哪项就在底稿里标「待补」并说明缺什么。

## 底层逻辑

- **四条主线**：增长、通胀、政策、金融条件；
- **一个约束**：风险（可能打断主线的风险）；
- **闭环**：监测 → 归因 → 预判 → 验证 → 复盘。

## 六步法（每步：看什么 → 怎么判断 → 输出什么）

### Step 0 定任务
定题再动笔：本次是判断景气（增长）、判断政策（是否降息/加码）、还是判断落地影响（房贷/配置）。
输出：【我要回答：未来（时间）（国家/地区）更可能（走强/走弱/维持），关键变量是 ___】

### Step 1 现状仪表盘
- 增长：中国看 PMI（50 荣枯线）、工业增加值、社零、固定资产投资（分项）；欧美看 PMI（制造+服务）、就业（失业率/新增）、零售。
- 通胀：中国看 CPI（含核心）+ PPI（企业利润与投资压力）；欧美看核心通胀 + 工资/服务通胀（粘性）。
- 金融条件：中国看政策利率与市场利率、社融结构、人民币汇率、DR007（银行间流动性水温计）；欧美看 2Y/10Y 美债、信用利差、美元指数。
输出：【目前经济：偏热/中性/偏冷；通胀：上行/下行/粘性；金融条件：偏松/中性/偏紧】

### Step 2 宏观季节（增长×通胀四象限）
增长（强/弱）×通胀（高/低）→ 复苏/过热/滞胀/衰退；判断政策约束来自通胀、增长、风险还是汇率。
- 欧美：更像「通胀—利率主导切换」（核心通胀决定降不降息）；
- 中国：更像「信用—投资主导切换」（信用能否传导到实体、投资能否形成开工更关键）。
输出：【目前更像第 X 象限，政策约束主要来自（通胀/增长/风险/汇率）】

### Step 3 拆解需求（找动力源）
GDP = C + I + G + (X − M)。
- 中国：投资驱动 + 制造业调度系统，重点拆投资（地产/基建/制造）与出口；消费常是后周期结果。传导：政策组合拳 → 银行信用扩张 → 钱投向基建制造 → 就业与需求。
- 欧美：消费驱动（美国个人消费约占 GDP 2/3），判断三件套：就业与工资、信贷成本、居民与企业资产负债表。传导：通胀 → 央行加息 → 借钱变贵 → 消费降温。
输出：【需求端：主要拉动来自 ___，主要拖累来自 ___，可持续性取决于 ___】

### Step 4 预判政策
- 中国（央行+财政）抓三问：信用传导通不通（社融/信贷结构）；地产链条有没有止跌信号（成交/开工/融资）；外部与汇率约束强不强。预判不只「降不降息」，还包括财政是否加码、地产规则是否优化、结构性工具是否加码。
- 欧美（美联储/ECB）抓两问：通胀是否回到目标；就业是否明显走弱、工资是否降温。
输出：【下一阶段政策更可能在 ___ 发力，主要因为 ___，但掣肘是 ___（通胀/汇率/金融风险）】

### Step 5 市场验证
观察：国债利率（钱的基础价格）、信用利差（融资难易/风险偏好）、汇率与美元（外部约束/资金流向）、股市波动率（风险偏好）。
中国重点：利率与信用环境、人民币、风险偏好、企业融资；欧美重点：2Y/10Y、信用利差、美元、股市。
输出：【市场定价与我的判断（一致/不一致）；若不一致，最大分歧点是 ___】

### Step 6 情景推演 + 风险清单
四类风险：金融（信用事件、流动性骤紧）、财政（债务压力、发债冲击利率）、外部（关税/战争/能源）、内部结构（地产/人口/生产率）。
- 中国最大风险：地产成交再走弱（地产—地方财政—银行风险偏好联动）；地方财政/化债节奏不及预期；外部摩擦影响出口订单。
- 欧美最大风险：核心通胀（服务/工资）再抬头导致高利率更久；财政赤字与国债供给推高长端利率；信用利差走阔引发融资收缩。
输出：【最大风险触发器是 ___；一旦发生，将通过 ___ 链条影响 ___】

## 收尾自检（六问）

现状（增长强弱/通胀上下/金融条件松紧）→ 定位（哪个象限）→ 拆解（谁拉动谁拖累）→ 预判（降息/观望/财政加码/定向支持）→ 验证（市场更乐观还是更悲观，分歧点）→ 行动（更进取还是更防守，盯哪个触发器修正）。

## 常见误用（禁止）

- 只堆数据不给结论（没有「输出」那三行）；
- 混用中美两套框架（拿美国的就业-工资逻辑套中国信用-投资链条）；
- 把四象限当预测工具（它只是给政策约束定位）；
- 用「大概率会涨」这类不可证伪表述；
- 数字没有来源却当成事实（本轮无证据池时一律标待补）。
